## 📌 Project Overview

**MinuteHire** is a HireKit-inspired Job Portal UI Clone developed using Angular and TypeScript as a portfolio and learning project.

The application focuses on delivering a modern, responsive, and user-friendly job portal experience. It demonstrates practical frontend development skills, component-based architecture, reusable UI components, and responsive interface implementation.

## ✨ Key Highlights

- Modern and responsive job portal interface.
- Component-based frontend architecture using Angular.
- Reusable UI components for maintainable code.
- Interactive user interface and navigation.
- Responsive layouts for different screen sizes.
- Live application deployment using Vercel.
